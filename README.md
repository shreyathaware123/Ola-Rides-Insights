# 🚖 Ola Ride Insights

**Ola Ride Insights is a data analytics project focused on extracting actionable business intelligence from ride-sharing data using SQL, Power BI, Python, and Streamlit.**

## # Project Objective

The objective of this project is to analyze OLA ride-sharing data to uncover insights that improve operational efficiency, optimize revenue strategies, and enhance customer satisfaction.

This project aims to:

* Identify peak booking hours and demand trends
* Analyze ride cancellations and their root causes
* Understand customer and driver rating patterns
* Evaluate revenue performance by payment method
* Deliver interactive business insights using Power BI and Streamlit

## 📂 Dataset Used

* **Dataset Name:** OLA Ride Dataset
* **Format:** CSV
* **Domain:** Ride-Sharing & Mobility Analytics
* **Columns**:
  
          1. Date & Time
  
          2. Booking_ID
  
          3. Booking_Status
  
          4. Customer_ID
  
          4. Vehicle_Type
  
          5. Pickup_Location
  
          6. Drop_Location
  
          7. V_TAT
  
          8. C_TAT
  
          9. Canceled_Rides_by_Customer
  
          10. Canceled_Rides_by_Driver
  
          11. Incomplete_Rides
  
          12. Incomplete_Rides_Reason
  
          13. Booking_Value
  
          14. Payment_Method
  
          15. Ride_Distance
  
          16. Driver_Ratings
  
          17. Customer_Rating
  
          18. Vehicle Images

##  Dashboard Overview

The Power BI dashboard provides interactive visual insights segmented into five major business areas:

### 1️⃣ Overall Performance

* Ride Volume Over Time
* Booking Status Breakdown

### 2️⃣ Vehicle Type Analysis

* Top 5 Vehicle Types by Ride Distance

### 3️⃣ Revenue Insights

* Revenue by Payment Method
* Top 5 Customers by Total Booking Value
* Ride Distance Distribution Per Day

### 4️⃣ Cancellation Analysis

* Cancelled Rides (Customer Reasons)
* Cancelled Rides (Driver Reasons)

### 5️⃣ Ratings Analysis

* Driver Ratings Distribution
* Customer Ratings Distribution
* Customer vs Driver Rating Comparison
